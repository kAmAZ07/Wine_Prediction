# Запуск

Проверено с Python 3.14.3. Версии библиотек указаны в requirements.txt.

Открыть терминал в папке wine_app и выполнить:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

После запуска открыть http://localhost:8501. Для остановки нажать Ctrl+C в терминале.

# Кэширование

Для модели используется st.cache_resource: он сохраняет один общий объект модели, который повторно используется при перезапусках скрипта.

Для таблицы и массивов вероятностей используется st.cache_data. Он сохраняет результаты чтения и вычислений и возвращает копии данных. При изменении порога вероятности берутся из кэша, а решения и метрики пересчитываются.

Без декоратора joblib.load заново читал бы файл и создавал объект модели при каждом перезапуске скрипта, в том числе после движения ползунка. Это увеличило бы время работы приложения.
